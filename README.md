# Portfolio - Aditya Shiralkar

A modern, responsive personal portfolio website.

## Tech Stack

- **React** - UI library
- **Vite** - Build tool
- **Tailwind CSS v4** - Styling
- **Framer Motion** - Animations
- **Lucide React** - Icons

## Features

- Responsive design
- Smooth animations
- Contact form (opens Gmail compose)
- Project showcase
- Skills & experience sections

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
